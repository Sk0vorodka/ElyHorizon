Minecraft: Java Edition, rewritten in Rust — played with ely.by accounts. No Microsoft account needed: your profile, your skin, your worlds.

Download for Windows View source

Free · open source · unofficial. You need your own copy of Minecraft: Java Edition.

What it plays like

🔑

ely.by accounts, two ways

Sign in to the launcher with your ely.by e-mail and password (two-factor accounts ask for the 6-digit code), or press Sign in with browser and finish an OAuth page at account.ely.by.

🧑‍🌾

Your ely.by skin

The launcher carries your skin to the game through the session file, so the world draws it without reaching ely.by while you play. Old accounts heal on the next launch.

🌍

Vanilla worlds, vanilla rules

The same terrain generation, mobs, redstone and saves as the Java game — checked against it by 281 differential harnesses. Reads your own legally obtained copy of Minecraft.

🧩

Mods in Rust

A mod is a small Rust crate compiled to a sandboxed WebAssembly component: HUD panels, a minimap, zoom, own screens with widgets, entities around you, the crosshair target, recipes, keys and storage.

🎮

Play with friends

Open to LAN, a hosted Horizon server without Java, or servers that accept ely.by sessions. Your friend on the Java game, you on the Rust one — same protocol.

⚡

Native, not Java

No Java runtime while you play: the client and the server are one Rust binary each, started by a small launcher that keeps itself and the game up to date.

Mods in Rust

A mod is a cdylib crate against the horizon-mod-sdk: declare your capabilities in horizon-mod.toml, export your mod, and the launcher's runtime runs it in a sandbox — no Java, no jar. Entities, the crosshair target, HUD, screens, recipes, input and storage are in the SDK today.

use horizon_mod_sdk::{Mod, Registration, entities, game, hud::{self, Corner, Line}};

struct Radar;
impl Mod for Radar {
    fn init() -> Result<(Self, Registration), String> {
        Ok((Radar, Registration::new().on_tick()))
    }
    fn tick(&mut self, _tick: u64) {
        let Some(player) = game::get_player() else { return };
        if let Some(near) = entities::list(32.0) {
            hud::set_panel(Corner::TopRight, &[Line {
                text: format!("{} entities nearby", near.len()),
                color: 0xFFFFFF,
            }]);
        }
    }
}
horizon_mod_sdk::export_mod!(Radar);

Worked examples: entity-radar, crosshair-hud, coords-hud and more. The full contract: horizon.wit.

The fine print

  • Free and open source, MIT-licensed — a fork of Horizon by Ludovic Marie.
  • Accounts by ely.by: password + 2FA, or OAuth in the browser; skins come with the account.
  • Works with Microsoft accounts too, exactly as upstream Horizon does.
  • Java mod jars do not run: Horizon's mods are Rust in a sandbox.

Not an official Minecraft product. Not approved by or associated with Mojang or Microsoft. ElyHorizon contains no Minecraft code, assets or data.
